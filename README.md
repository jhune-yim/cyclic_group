# Primitive roots modulo n

`cyclic_group_cli.lisp` checks whether the multiplicative group of units modulo `n`, written `U(n)`, is cyclic. For a cyclic group, it prints Euler's totient `phi(n)` and all primitive roots in ascending order.

## Run with SBCL

SBCL(Steel Bank Common Lisp) is the only dependency. Run the commands below from the directory containing the script.

**Interactive mode**

```sh
sbcl --script cyclic_group_cli.lisp
```

Enter one decimal integer of at least 2 per line. Enter `q` or `Q` to quit, or send end-of-file with Ctrl+D on Unix-like terminals. After an invalid entry, the script reports the error and prompts again.

**Batch mode**

```sh
sbcl --script cyclic_group_cli.lisp 7 15 18
```

The script processes valid moduli in argument order and writes their results to standard output. Each invalid argument produces a diagnostic on standard error. The command exits with status `1` if any argument is invalid and `0` otherwise. A noncyclic group such as `U(15)` is a valid result.

**Built-in examples**

```sh
sbcl --script cyclic_group_cli.lisp --demo
```

Pass `--demo` by itself to run the examples for `7`, `10`, `15`, and `18`.

## Example output

For modulus `18`, the script prints the following result.

```text
===== n = 18 =====
U(18) is cyclic.
Euler's totient phi(18) = 6
Number of generators: 2
Primitive roots: (5 11)
```

## Algorithm

For `n >= 2`, the group `U(n)` is cyclic exactly when `n` is `2`, `4`, `p^k`, or `2p^k`, where `p` is an odd prime and `k >= 1`. The script reuses the prime found during this check to compute the totient for `p^k` and `2p^k`.

For a cyclic group, the script tests candidates until it finds a primitive root `r`. For each distinct prime divisor `q` of `phi(n)`, a candidate must be a unit whose power at exponent `phi(n)/q` differs from 1 modulo `n`. Once the script finds `r`, it generates successive powers with one modular multiplication per step. The powers with exponents `k` satisfying `gcd(k, phi(n)) = 1` are exactly the primitive roots.

The script uses trial division and stores the full list before sorting and printing it. For large moduli, factorization, enumeration, and output can all affect runtime.
